[2] 合并前修复（收口）
================================================================================
上一轮会话遗留未提交改动 src/helpers/database.js（声纹 upsert 冲突目标）：
    - ON CONFLICT(source_profile_id) DO UPDATE SET ...
    + ON CONFLICT(source_profile_id) WHERE source_profile_id IS NOT NULL DO UPDATE SET ...

复现与验证（sqlite3 CLI，使用与代码一致的建表/索引语句）：
    CREATE UNIQUE INDEX idx_voiceprints_source_profile
      ON voiceprints(source_profile_id) WHERE source_profile_id IS NOT NULL;

  旧写法：Error: in prepare, ON CONFLICT clause does not match any PRIMARY KEY
          or UNIQUE constraint
  新写法：（无错误）→ 命中既有行并更新，SELECT 结果为 `1|1|4|77`

结论：SQLite 对**部分唯一索引**要求 ON CONFLICT 目标重复索引的 WHERE 谓词；旧写法语句
无法 prepare，导致声纹样本永远无法更新既有档案行（属 2.0.5 新功能范围内的真实缺陷）。
已作为 f84f91f4 提交并入 PR #10（rebase 后为 d7022648）。
